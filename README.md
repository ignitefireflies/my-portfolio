# Abhi Dinkale — AI Engineer & Product Builder Portfolio

A high-performance, responsive, and aesthetically premium personal portfolio built with React, Vite, Tailwind CSS, TypeScript, and Framer Motion. 

Designed around **Retro CRT × AI Laboratory × Modern Minimalism** aesthetics: terminal telemetry headers, scanline CRT overlays, multi-agent architecture flow diagrams, live radar tracking, and categorized project filtering.

## Tech Stack

- **Core & Routing:** [React 18](https://react.dev/) & [React Router v6](https://reactrouter.com/)
- **Build Tool:** [Vite 6](https://vite.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) with custom typography (`Amiamie` & `Instrument Serif`)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & GSAP for smooth micro-interactions, layout entries, and telemetry animations
- **Icons:** [lucide-react](https://lucide.dev/) & [@iconify/react](https://iconify.design/)
- **Analytics:** [@vercel/analytics](https://vercel.com/docs/analytics)

## Features & Sections

- **Terminal Telemetry HUD & Status Bar:** Live system status (`SYS://STATUS: ONLINE`, `BUILDING: AI PRODUCTS`, `FOCUS: AI × PRODUCTS × AGENTS`, `LOC: INDIA`).
- **Enormous Flagship Showcases:**
  - **PROTON (AI × Healthcare):** Clinical data ingestion, Whisper speech-to-text, Tesseract OCR, and FHIR interoperability pipeline with interactive 5-stage architecture breakdown.
  - **OBSEDIAN (AI × Quant Finance):** Autonomous hedge fund in a box for simulated & paper trading with a complete 9-stage multi-agent pipeline flow (`MARKET DATA` → `RESEARCH AGENTS` → `AI ANALYSTS` → `STRATEGY` → `PORTFOLIO` → `RISK` → `TRADE` → `PAPER TRADING` → `PERFORMANCE ANALYSIS`).
- **Domain Explorer ("What I Build"):** 7 specialized areas covering AI Agents, Generative AI, AI Products, HealthTech, AI × Finance, EdTech, and CareerTech.
- **Currently Building Live Radar:** Pulsing tracking cards for active products (Proton, OBSEDIAN, Open Opportunity, Teachly).
- **Categorized Project Filtering:** Filter systems dynamically by `ALL`, `AI`, `AI AGENTS`, `HEALTHTECH`, `FINTECH`, `EDTECH`, and `CAREERTECH`.
- **Applied Tech Stack:** Real contextual usage per technology instead of arbitrary percentage skill bars.
- **Interactive Command Palette (`⌘K` / `Ctrl+K`):** Keyboard-driven menu to jump directly to any system, flagships, or external links.
- **Easter Eggs:** Type `"abhi"` or `"dinkale"` or the classic Konami sequence (`↑ ↑ ↓ ↓ ← → ← → B A`) to trigger custom celebration effects.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the local development server:
```bash
npm run dev
```

3. Build for production:
```bash
npx vite build
```

## Configuration

Modify [`src/config/site.ts`](src/config/site.ts) to update personal data, links, flagship specifications, or project details.
